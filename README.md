# 🐍 Classic Snake Game - Python Tkinter
Proyek ini adalah aplikasi game desktop "Snake" yang dibangun menggunakan bahasa pemrograman **Python** dan pustaka **Tkinter**. Proyek ini merupakan bagian dari eksplorasi komponen kode dasar dan implementasi nyata dari materi pemrograman berorientasi objek (OOP) di sekolah.

## 🛠️ Fitur Utama & Logika yang Diterapkan
- **Responsive Controls:** Kendali ular yang responsif menggunakan tombol Arrow (Panah) atau kombinasi `W, A, S, D`.
- **Anti-Self Collision Logic:** Sistem validasi arah agar ular tidak bisa berputar balik menabrak badannya sendiri secara instan.
- **Dynamic Colorful Body:** Menggunakan fungsi `random_color` dan struktur data *List* untuk mengelola koordinat badan ular agar bertambah panjang dengan warna acak saat memakan buah.
- **Game Loop:** Menggunakan metode `.after()` untuk pembaruan logika permainan dan menggambar ulang objek pada Canvas secara asinkron setiap 90ms.
- **Smart Window Centering:** Aplikasi otomatis mendeteksi resolusi layar dan memosisikan jendela game tepat di tengah monitor.
